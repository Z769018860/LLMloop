## 原研究方向与现状

原题：LLM-Guided Certified Loop Acceleration via Periodic Invariants and
Compositional State Summaries。贡献应超过“LLM 猜不变式，再减少展开”，重点放在
精确状态转换、周期与单调状态共同演化、typed 源码证明和实际入口的嵌套组合。
代价/概率属于扩展方向；QCP-inspired 的早期设想没有形成可据以声称完整复现的证据。

| 研究环节 | 当前证据/实现 | 还不能声称什么 |
| --- | --- | --- |
| 周期/递推摘要 | SPath/SCC、选定周期变换、矩阵/多项式闭包、受限自动候选、独立验证 | 任意状态分支/任意耦合递推自动闭式 |
| C 语义 | ABI-aware 类型、转换、溢出/移位/除法等原始中间运算检查 | 通用 C/LLVM 语义或已验证编译器 |
| 嵌套组合 | entry 绑定、父子上下文检查、独立子摘要证明 | 任意 CFG/别名/递归堆组合 |
| 候选与回退 | 本轮新增 typed 候选组合与显式有界回退，失败和未尝试候选保留 | 已测得真实 LLM 增益、最优代价策略 |
| LLM 接口 | 数学 cycle/invariant 的可选远程提案接口；typed supplied-candidate 验证入口 | typed 轨迹的完整真实模型实验与收益归因 |
| 核心摘要控制 | v0.20 保留 136 个预先定义的期望结果，含周期/嵌套/阈值正例及错误候选/未定义/不支持控制 | 不能把期望拒绝也算作“支持程序”或代表性精度 |
| 工程验证 | v0.58：3,161 测试、6,384 次原生输出对照；本轮有独立 v0.59 记录 | 这些数字等于独立程序覆盖率、精度或加速比 |
| 真实代码 | v0.43：13 函数/15 输入域，默认与附加证明策略分别记账 | 整个 compiler-rt 或代表性工业程序覆盖 |

## 仍缺的通用功能（不必全部做完才写这篇论文）

- 任意耦合/分支递推自动发现，任意循环退出与无界终止性推断。
- 通用堆形状、别名/所有权契约、跨过程状态修改与递归堆归纳。
- 广义外部库/函数指针/变参，浮点、字节内存/effective types、一般 union、并发。
- 广义 VLA 参数/多维布局、VM 类型名副作用，以及未覆盖的源码/LLVM 指令语义。
- 代表性实证、稳健的 live-LLM 到 typed 轨迹提案流程、总预算控制与经过实证的策略选择。

KLEE 当前有意不集成，不作为投稿的强制缺口。内存访问代价、概率质量不是这篇稿的
已实现贡献；若以后纳入，需要独立验证精确值或界，不能替换为循环上界。

## 本轮验证稳定性

首轮顺序回归中有两项原有除法归纳测试失败，隔离复查均通过。首轮被中断后未能
恢复详细断言栈，不能据此推断具体原因或宣称修复了产品缺陷。后续采用两个不重叠
测试分组重跑全部项目，保留逐项事件和原时限。原始失败、隔离检查和完整重跑分别
归档；求解/运行稳定性和失败运行透明度仍是投稿前需要审查的事项。

后续专门诊断进一步记录了旧除法测试中的单查询 timeout。已加入保持源对应等式
和全部安全义务的 Boolean-product/守恒式等价重写，三个 ABI 原型与 102 项定向
测试通过。最终完整回归和原始源码重放仍单独验收；此修正不意味着消除了所有运行时/求解器波动。

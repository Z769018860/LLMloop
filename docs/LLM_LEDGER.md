# LLM 实验总账 / the whole bill

> 本页由 `python scripts/llm_ledger.py` 从各 `results.json` 重算，**不含**人工填写的数字。每个数字都能用一条命令复现；`--check` 会在文档与数据不一致时以非零码退出。Generated, not transcribed.

## 1. 口径 / what counts

- **调用 / call**：真正发出去的请求数。v1.03 那两臂每个程序多轮生成，所以调用数多于单元数；其余各臂一单元一次调用。
- **有 usage 的回答 / answers with usage**：只有这些才贡献 token。E6b 曾有 231 次调用被 `HTTP 403` 拒掉（余额为负），既没有 `usage` 也没有计费；那 231 个单元已于 2026-11-27 补齐，现在这一臂 249/249 全部有 usage。
- **缓存命中 / cache hit**：请求体与某次已付费的调用逐字节相同，答案从磁盘返回，**0 次调用**。v1.09 的 repeat 0 就是这样复用了 v1.07 的 83 行，所以它 249 个单元只付了 166 次。
- **钱 / money**：端点 `api.square16.org` 是代理，它的账单不在仓库里，所以金额是**按公开价目代入的估算**，不是发票。价目与敏感度在 §4。
- **不计入 / not counted**：只读的本地分析、`merge`、对照臂的求解尝试（1,481 + 46 次，零模型调用）、以及被缓存命中的重放（0 调用）。

## 4. 价目与敏感度 / prices, and how much the total depends on them

| 模型 | 输入 USD/M | 输出 USD/M | 依据 |
| --- | --- | --- | --- |
| `gpt-4.1-mini` | 0.40 | 1.60 | OpenAI 公开价目（2025-04） |
| `claude-sonnet-4-5-20250929` | 3.00 | 15.00 | Anthropic 公开价目 |
| `deepseek-v4.1-flash-ark` | 0.15 | 0.60 | DeepSeek 官方 flash 价目（2026-11 核对）；别名可能含代理加价 |

| 情境 | 估算总额 |
| --- | --- |
| 价目 × 0.5 | 13.49 |
| **声明价目** | **26.98** |
| 价目 × 2 | 53.96 |

所以正确的句子是「**十到五十美元量级**」，不是「26.98 美元」。这个精度足够回答本节的问题（哪一臂贵、哪一臂便宜、把没跑的那一臂补上要多少钱），不足以报销。

## 5. 曾是 void 的那一臂，和补上它的价钱 / the arm that was void, and what closing it cost

E6b 在 2026-11-23 只答了 18 个单元就被 `HTTP 403 Insufficient user quota` 挡住，余额被打成负数。它因此在论文 §4o 里写作 void、不参与判定，那 18 个答案只作记录保留。

2026-11-27 补齐：233 个空单元重新发送（旧目录移进 `raw_void_billing/` 归档，不删——那批空回答本身就是余额事件的证据），其余 16 个原样保留。现在 **249/249 全部有答案**。

| 项 | 值 |
| --- | --- |
| 单元 | 249（补齐前 18 个有 usage、其中 16 个解析成功；233 个无任何回答） |
| 整臂 token | 110,337 prompt / 1,666,913 completion |
| 整臂估算 | **1.02 USD**（其中 233 个单元是本轮新付，约 0.95） |
| 每次 completion：中位 | 4,987 tokens |

**补齐之后这一臂不再是 void，而它给出的答案是反向的**：deepseek @16k 证出 **13/83**，对照 17/83；`t = 0` 上仅 S 为 2、仅 B 为 6，精确 McNemar **p = 0.289，不显著**。2048 上限的两个臂（E6c、E6d）是 4–5/83 与 p ≈ 0.001。也就是说「模型更差」这句话**取决于上限**，而这篇文章从 §4p 起就在说上限是混淆变量——现在它自己撞上了同一个问题。这一条已写进论文 §4r。它不给任何正向主张背书：13 对 17 仍然落后，只是不再显著落后。

价格上，这把「要不要把那个 void 补上」从立场问题变成了价格问题：**不到一美元**。而这份总账里最贵的是两个早已有结论的臂（v1.04 及其 16k 追加）。

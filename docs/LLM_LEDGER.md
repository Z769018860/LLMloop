# LLM 实验总账 / the whole bill

> 本页由 `python scripts/llm_ledger.py` 从各 `results.json` 重算，**不含**人工填写的数字。每个数字都能用一条命令复现；`--check` 会在文档与数据不一致时以非零码退出。Generated, not transcribed.

## 1. 口径 / what counts

- **调用 / call**：真正发出去的请求数。v1.03 那两臂每个程序多轮生成，所以调用数多于单元数；其余各臂一单元一次调用。
- **有 usage 的回答 / answers with usage**：只有这些才贡献 token。E6b 的 249 次调用里 231 次被 `HTTP 403` 拒掉，没有 `usage`，也没有计费。
- **钱 / money**：端点 `api.square16.org` 是代理，它的账单不在仓库里，所以金额是**按公开价目代入的估算**，不是发票。价目与敏感度在 §4。
- **不计入 / not counted**：只读的本地分析、`merge`、对照臂的求解尝试（1,481 + 46 次，零模型调用）、以及被缓存命中的重放（0 调用）。

## 4. 价目与敏感度 / prices, and how much the total depends on them

| 模型 | 输入 USD/M | 输出 USD/M | 依据 |
| --- | --- | --- | --- |
| `gpt-4.1-mini` | 0.40 | 1.60 | OpenAI 公开价目（2025-04） |
| `claude-sonnet-4-5-20250929` | 3.00 | 15.00 | Anthropic 公开价目 |
| `deepseek-v4.1-flash-ark` | 0.28 | 0.42 | **假设**：代理上的内部别名，按 DeepSeek 公开价目代入 |

| 情境 | 估算总额 |
| --- | --- |
| 价目 × 0.5 | 12.46 |
| **声明价目** | **24.92** |
| 价目 × 2 | 49.85 |

所以正确的句子是「**十到五十美元量级**」，不是「24.92 美元」。这个精度足够回答本节的问题（哪一臂贵、哪一臂便宜、把没跑的那一臂补上要多少钱），不足以报销。

## 5. 没买的那部分 / the arm that was frozen and never paid for

E6b 的 231 次调用被 `HTTP 403` 挡在门外（余额为负），账户没有为它们付钱，这一臂因而是 void。把答案数量按已答的 18 个外推：

| 项 | 值 |
| --- | --- |
| 剩余调用 | 231 |
| 每次 completion：均值 / 中位 | 6133 / 5784 tokens |
| completion 合计（两条统计各推一次） | 1,335,988 – 1,416,800 tokens |
| prompt 合计 | 98,676 tokens |
| 按声明价目 | **0.59 – 0.62 USD** |
| 按价目 × 2 | 1.18 – 1.25 USD |

**这把「要不要把那个 void 补上」从立场问题变成了价格问题：不到一美元。** 它此前被写成「1.4 M token」，读起来像一大笔钱；换算之后它是这份总账里最便宜的一件事，而它是唯一还未回答的问题。反过来，最贵的是两个早已有结论的臂（v1.04 及其 16k 追加），它们买了 3 个净新增证明、p 分别为 0.375 与 0.25。

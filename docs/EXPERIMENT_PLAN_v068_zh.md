# v0.68 局限修复与待补实验规划

## 已完成（本轮）
- `typed_invariant_tree` 新增关系型合取 `@rel`：`{"eq":[expr…], "le":[expr…]}`（expr ≤ 0 / = 0，可引用状态变量、参数与迭代计数；≤8 条）。验证器仍在任意类型化状态上检查入口/归纳/出口，LLM 输出不被信任；规范化器保留 `@rel`。测试 `tests/test_typed_invariant_rel.py`（5 项：箱形不足而关系可证、仅关系可证、假/非归纳关系被拒、畸形输入被拒、不安全程序不被认证）。
- 诚实说明：目前只有单元/性质级证据，**尚无 LLM 实验**证明关系型提示带来增益；"增强"在此仅指表达力，不是经验结论。

## 仍未解决的局限
1. 内层循环边界依赖可变状态；`while`/`do-while`；循环内声明/早退；循环位于 `if` 内。
2. 关系型不变式尚无 Spacer/CHC 同口径对比（Spacer 对关系型较强，需公平比较）。
3. 语料均为合成程序（33/48/17 个），无真实代码；无多重比较校正。
4. 弱模型（gpt-4.1-mini、glm）输出格式失败占比高；修复循环仅 +1～+2/27。

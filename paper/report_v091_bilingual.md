# v0.91 报告 / Report (中文 / English) — 面向正会的补充实验 / experiments added for a main-track submission

## 中文
**实验 A:证书独立复核(CBMC)。** 把已认证的 C 语义循环不变式(Houdini 42 个 + LLM 提出且被认证的 199 个不同不变式,共 241 个)翻译成 CBMC 循环契约(`goto-instrument --apply-loop-contracts`),让 CBMC 独立证明无除零/有符号溢出。结果:**238/241 被 CBMC 独立验证**,2 个 FAILED,1 个转换错误(Python 风格 `max` 嵌套的原子,未转换成功)。两个 FAILED 恰好是下面实验 B 找出的失效旧证书。复核脚手架本身出过 4 个缺陷(`nondet_bool` 未建模、参数重命名、`max()` 被当作有副作用、Python 条件表达式),均已修复并重跑,没有挑选结果。
**实验 B:存量认证复核(重要更正)。** 用**当前**验证器重新验证全部 695 条存量"已认证"LLM 响应(C 语义 286、数学整数 409):各有 **4 条不再成立**(共 8 条),原因是 v0.79 修复的"被代码修改的形参应视作循环状态"缺陷;这些旧证书对应 `benchmark51_polynomial`(`x<=51` 的不变式其实不足以证明断言)、`benchmark20_conjunctive` 等程序。被影响的程序都仍被其他模型认证,**程序级计数不变,响应级计数 286→282、409→405**。这说明早期论文数字里确有"验证器缺陷导致的错误认证",虽然这些程序本身是安全的(不是预期违反的程序被误认证),CBMC 独立确认了它们失效。
**实验 C:留出集(冻结工具链,未用 LLM)。** 新目录 `nla-digbench`、`loops-crafted-1`(此前从未使用,sv-benchmarks @2e1723f),105 个程序;冻结提交 `ea0aa25`。翻译进入片段 37 个,其中可判定 29 个(预期成立 22、预期违反 7)。结果:我方 Houdini + 未改动验证器认证 **2/22**(数学与 C 模型相同),预期违反 **0/7 被认证**;Ultimate **8/22**、CPAchecker **5/22**、ESBMC **1/22**(ESBMC 另在 7 个违反程序中找到 2 个),四者都 0 误判。结论:**在非线性多项式不变式主导的留出集上我方明显弱于 Ultimate/CPAchecker**。首轮 Ultimate/CPAchecker 因孤儿 JVM 占满内存几乎全部超时,已作废(文件 `*_run1_memory_starved.json` 保留),用 2 线程 + 进程清理重跑。
**实验 C′(事后,不属于留出结论):** 看过留出失败后修了翻译器("先声明、后赋值"的局部变量,首次提及是无条件顶层赋值时给 0 初值,该值不可观测;对旧语料只改变 2 个原本被拒的程序)。覆盖 37→67/105;可判定 51 个(成立 42/违反 9):认证 **4/42**,违反 0/9。
**实验 D(未成功,默认关闭):** 多项式等式挖掘(`POLY_DEGREE`)。它能从样本中挖出 `z=6n+6`、`y=3n²+3n+1` 等正确不变式,循环保持性通过,但出口义务在非线性求解上卡住(无反例的 UNKNOWN),`cohencu` 仍未认证。
**未做(受阻):** 留出集上的 LLM 实验——当前环境没有 LLM 凭据(历史研究的密钥未入库,也不应入库)。
**对正会投稿的含义:** 实验 A、B 加强了"证书可独立复核 + 误认证被发现并披露"的叙事;实验 C 暴露了泛化弱点,必须如实写入。仍缺:族不相交的留出 LLM 实验、非线性不变式能力、与最强基线同任务的优势证据。

## English
**A. Independent certificate re-check (CBMC).** 241 distinct certified C-semantics invariants (42 Houdini + 199 LLM-proposed) were turned into CBMC loop contracts; CBMC independently proves no division by zero / signed overflow: **238/241 verified**, 2 FAILED, 1 conversion error. The 2 FAILED are exactly the stale certificates found in B. The harness itself had 4 defects (unmodelled `nondet_bool`, parameter renaming, `max()` flagged as side effect, Python conditionals); all fixed and re-run, nothing cherry-picked.
**B. Stored-certificate audit (correction).** All 695 stored "certified" LLM responses (C 286, math 409) were re-verified with the CURRENT verifier: **4 + 4 no longer hold**, because of the v0.79 fix "parameters modified in the code are loop state". Affected programs are still certified by other models: program-level counts unchanged; response-level 286→282 and 409→405. Earlier numbers therefore contained verifier-bug-induced false certificates (of safe programs, not of expected-violating ones); CBMC independently confirms they fail.
**C. Held-out study (frozen toolchain, no LLM).** Never-used directories `nla-digbench`, `loops-crafted-1` (105 programs; freeze commit `ea0aa25`): 37 enter a fragment, 29 decidable (22 valid, 7 violated). Ours (Houdini + unchanged verifier) certifies **2/22**, 0/7 violated; Ultimate **8/22**, CPAchecker **5/22**, ESBMC **1/22** (+2/7 violations found); no tool misjudges. **We are clearly weaker than Ultimate/CPAchecker on this polynomial-invariant-heavy held-out set.** The first Ultimate/CPAchecker run was void (orphan JVMs exhausted memory); kept as `*_run1_memory_starved.json`, re-run with 2 threads and process reaping.
**C′. Post-hoc (not a held-out conclusion).** After seeing failures the translator was fixed (declared-then-assigned locals); it changes only 2 previously rejected old-corpus programs. Coverage 37→67/105; decidable 51 (42 valid/9 violated): **4/42** certified, 0/9.
**D. Negative/partial:** polynomial-equality mining (off by default) finds the right invariants and loop preservation passes, but exit obligations stall on nonlinear solving; `cohencu` stays uncertified.
**Blocked:** LLM runs on the held-out set (no credentials in this environment).
**Implication:** A and B strengthen the "independently checkable certificates, bugs found and disclosed" story; C exposes a generalisation weakness that must be reported. Still missing for a main track: family-disjoint held-out LLM study, nonlinear-invariant capability, a same-task win over the strongest baseline.
